# Lume Tool

Ponytail modified to specialize on Lume + Missing.CSS which is the stack used in
this repository.

Usage outside here is discouraged.

## USER WARNING

This won´t magically turn your robot into a Senior Dev like it claims to do. It
will roleplay to hell and beyond that it's a "Senior Dev" but with a few
1955-style lobotomizations.

### Usability warnings

- Commands live under `.opencode/command`

- The `lume-tool-debt` command is mostly useless as you can run the script
  yourself. Unless you are way too lazy or have money to gift to your token
  sellers.

- The `ponytail-gain` skill WON'T be added since benchmarking prompts is weird
  given their non-deterministic nature.

- Both `package.json` and `node_modules` are symlinked to `/dev/null` so
  OpenCode doesn't do it's stupid project initialization everywhere via bun.

Don't take anything for granted with this variant.
