Harvest every `DEBT:` comment in this repository into a debt ledger so deferrals
do not rot into 'later means never'. **NEVER** grep the whole tree for comment
markers, use the safe, deterministic Deno script to harvest all debt markers
across the codebase without modifying any files.

To run the harvester at the project root run `deno task harvest_debt` to handle
permissions and extra flags automagically.

Output the exact report generated by the script without modifying any code or
commentary.
