# ROBOT INSTRUCTIONS

Instructions file for text generating robots.

## Architecture

- **Stack**: Lume (Deno static site generator) + missing.css + TypeScript/JSX
- **Source**: `src/` contains pages, components and styles
- **Output**: `output/` (autogenerated, never edit directly)
- **Config**: `_config.ts` (Lume plugins, googleFonts, build pipeline)
- **Components**: `src/components/*.tsx` (JSX/TSX)
- **Styles**: `src/styles.css` do not edit `output/`

## Critical: Font & CSS Stack

Font loading is handled by `googleFonts` plugin in `_config.ts`:

- Plugin downloads Google Fonts and generates proper `@font-face` rules
- Output goes to `output/urutau.css` (autogenerated)
- `src/styles.css` gets appended to the same file
- **Never manually write `@font-face` rules in `src/styles.css`** — the plugin
  handles it

missing.css provides:

- Classless base styling for vanilla HTML
- Utility classes with **literal angle brackets**: `.<h2>`, `.<small>`,
  `.<button>`, `.<big>`
- Font CSS variables: `--main-font`, `--display-font`, `--secondary-font`,
  `--mono-font`
- Override these in `:root` to control fonts across the site

When styling elements that use missing.css masquerades (e.g.,
`<p class="<h2>">`), remember they inherit missing.css utility styles. Set CSS
variables in `:root` to propagate fonts properly.

## Quirks

- Custom `nyc` CLI tool exists (only in guix shell) — checks front matter,
  metadata, email leaks
- `genmail.pl` script encodes emails for anti-spam (see README)
- Site content is primarily in Spanish
- Uses JSR imports (`jsr:@std/...`) and CDN imports for Lume
- `deno.json` has custom permission profiles for Lume tasks

## When Working with Styles

1. Check if missing.css already provides what you need (classless defaults or
   utility classes)
2. Override via CSS variables in `:root` when possible
3. Only add custom CSS rules for truly custom styling
4. Remember: `!important` is valid when overriding missing.css cascade order
   (add comment explaining why)
